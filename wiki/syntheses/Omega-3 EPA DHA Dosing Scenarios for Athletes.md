# Omega-3 EPA DHA Dosing Scenarios for Athletes

這頁整理使用者提供的 EPA+DHA 劑量表，作為運動營養實務備忘。它不是醫療處方；實際使用仍應依飲食 EPA/DHA 攝取、[[Omega-3 Index]]、訓練負荷、比賽期、藥物、凝血風險與心血管病史調整。

## Scenario Table

| 人群 / 場景 | 建議 EPA+DHA | 建議週期 | 主要目的 |
|---|---:|---|---|
| 普通健身 / 日常訓練 | 1000 mg / 天 | 長期 | 基礎健康、抗炎、維持指數 |
| 高訓練量 / 備賽期 | 1000-2000 mg / 天 | 4-8 週 | 恢復、降低酸痛、耐力支持 |
| 力量訓練 / 恢復差 | 1500-2000 mg / 天 | 2-6 週 | DOMS 恢復、力量輸出 |
| 耐力運動員 | 1000-2000 mg / 天 | 長期 | 跑步經濟性、心血管支持 |
| 拳擊 / 足球 / 頭部沖擊運動 | 約 2000 mg / 天 | 賽季期 | 神經保護、恢復 |
| 普通健康人最低建議 | 500-600 mg / 天 | 長期 | 基礎攝入底線 |

## How to Read This Table

- `EPA+DHA` 指總 EPA 加 DHA，不是魚油總重量。
- 若飲食中已經規律吃高 EPA/DHA 魚類，補充需求可能較低。
- 若 O3i 偏低，補充或飲食調整的優先性較高。
- 若目標是運動恢復，較合理的 endpoint 是 DOMS、CK/LDH、主觀疲勞、訓練輸出與下一次訓練品質。
- 若目標是耐力或心血管支持，應同時追蹤心肺訓練、血脂、睡眠與整體飲食品質。
- 若是接觸運動或頭部撞擊風險，omega-3 只能視為潛在輔助，不能取代防護、技術、規則與醫療評估。

## Evidence Notes

[[Jager 2025 - ISSN Position Stand Long-Chain Omega-3 PUFAs]] 支持運動員可能有較高 omega-3 不足風險，並將 EPA/DHA 與耐力、心血管功能、肌力、恢復、免疫、睡眠與頭部撞擊保護分開討論。

[[Heileson 2025 - Omega-3 Index in Athletes]] 顯示運動員 O3i 普遍偏低，因此劑量表最好搭配狀態評估，而不是直接套用。

[[Fernandez-Lazaro 2024 - Omega-3 Post-Exercise Inflammation and Muscle Damage]] 顯示 omega-3 對部分運動後發炎、肌肉損傷與氧化壓力 marker 可能有利，但 DOMS 結果混合，performance outcome 不穩定。

[[Djuricic 2025 - EPA DHA and Cardiovascular Health]] 提醒，高劑量 omega-3 需要考慮個體風險，特別是心房顫動、出血風險、藥物與臨床背景。

## Practical Decision Rule

1. 先確認每週魚類與 EPA/DHA 攝取。
2. 有條件時測 O3i。
3. 根據場景設定 endpoint：健康、恢復、耐力、肌力、睡眠或 neuroprotection。
4. 從較低可行劑量開始，觀察 4-8 週。
5. 高劑量或長期補充要納入醫療與用藥風險。
